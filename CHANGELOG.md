## [0.1.0] - 2026-03-28

### Added
- Initial GovCore Django template scaffold

- Optional feature generation for auth, API, docs, MFA, and tenancy
- Custom UUID user model and identity module skeleton
- Core primitives (models, exceptions, pagination, audit)
- Celery + Redis task queue setup
